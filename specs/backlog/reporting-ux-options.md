## Problem

Improve aggregated reporting ergonomics with alternative history layouts and export-friendly
output.

## Expected outcomes

- History aggregated balance reporting can render either long or wide table output
- Non-interactive aggregated history reporting can emit CSV output for downstream analysis
- Output-format options are defined in a way that preserves current default behavior unless the
  user opts in
